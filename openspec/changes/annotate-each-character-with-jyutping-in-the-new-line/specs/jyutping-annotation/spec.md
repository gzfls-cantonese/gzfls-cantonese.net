# Spec Delta

## Purpose

为《三国演义》粤语评书脚本的每个汉字提供带声调的粤拼标注，并在脚本面板中与繁体文本逐字对齐地显示，帮助粤语学习者在听读同步过程中掌握每个字的发音。

## ADDED Requirements

### Requirement: 构建期逐字粤拼生成

系统 SHALL 在数据管线抽取阶段，为每条记录的繁体 `transcription` 生成逐字粤拼，粤拼 MUST 带声调数字（如 `sam1`、`gwok3`）。生成 MUST 以「逐字」为粒度并与 `transcription` 的字符序列一一对应，使前端无需在运行时做任何转换。

#### Scenario: 为一条记录生成粤拼

- **WHEN** 管线处理一条含繁体文本的记录
- **THEN** 为该记录产出与其字符序列逐一对应、带声调数字的粤拼标注

#### Scenario: 非汉字字符留空占位

- **WHEN** 文本中包含标点、数字、空格等非汉字字符
- **THEN** 这些字符在粤拼标注中对应位置为空占位，不产生粤拼，但保持与上方字符的位置对应关系

### Requirement: 粤拼数据契约与降级

系统 SHALL 将逐字粤拼作为按集 JSON 索引中每条 entry 的新增字段随静态资产分发。当某条 entry 缺少粤拼字段（例如资产尚未用新管线重建）时，脚本面板 MUST 优雅降级为不显示粤拼行，且 MUST NOT 报错或中断繁体文本与音频的正常展示与播放。

#### Scenario: 存在粤拼字段

- **WHEN** 前端加载的 entry 含有粤拼字段
- **THEN** 脚本面板据以渲染对齐的粤拼行

#### Scenario: 缺少粤拼字段时降级

- **WHEN** 前端加载的 entry 不含粤拼字段
- **THEN** 脚本面板正常显示繁体文本并可播放音频，粤拼行不显示，且不抛出错误

### Requirement: 繁体下方对齐显示粤拼行

系统 SHALL 在脚本面板每条繁体文本的下方新增一行粤拼，粤拼 MUST 与上方汉字逐字对齐（在文本换行时对每一视觉行同样保持字与粤拼的上下对齐）。粤拼行 MUST 保持繁体文本原有的记录顺序、当前句高亮、自动滚屏与点击定位行为不受影响。

#### Scenario: 显示对齐的粤拼

- **WHEN** 用户进入某集详情页且 entry 含粤拼
- **THEN** 每条繁体文本下方显示逐字对齐的粤拼行

#### Scenario: 文本换行时仍对齐

- **WHEN** 一条脚本文本因宽度不足而换行
- **THEN** 每个换行后的视觉行中，汉字与其粤拼仍逐字上下对齐

#### Scenario: 高亮与定位不受影响

- **WHEN** 播放进行或用户点击某条脚本行
- **THEN** 当前句高亮、自动滚屏与点击定位行为与新增粤拼行前一致

### Requirement: 粤拼显示开关

系统 SHALL 在脚本区提供粤拼显示开关，默认状态为显示。用户 MUST 可切换该开关以显示或隐藏粤拼行；关闭时脚本面板 MUST 仅显示繁体文本，且该切换 MUST NOT 影响音频播放与当前句状态。

#### Scenario: 默认显示粤拼

- **WHEN** 用户首次进入某集详情页
- **THEN** 粤拼开关处于显示状态，繁体文本下方展示粤拼行

#### Scenario: 切换隐藏粤拼

- **WHEN** 用户关闭粤拼开关
- **THEN** 粤拼行隐藏，仅显示繁体文本，播放与当前句高亮保持不变
