# Spec Delta

## Purpose

让用户浏览并导航完整 157 集《三国演义》粤语评书，快速进入任意集收听，并看到每集的元信息与经典小人书封面。

## ADDED Requirements

### Requirement: 分集列表导航

系统 SHALL 展示全部 157 集的导航列表，每项显示集号与标题，并支持按集号定位。列表 MUST 从全局清单加载，缺失或加载失败时给出可见的错误提示与重试入口。

#### Scenario: 打开首页查看列表

- **WHEN** 用户进入首页
- **THEN** 显示 157 集的可滚动导航列表，每项含集号与标题

#### Scenario: 清单加载失败

- **WHEN** 全局清单请求失败
- **THEN** 显示错误提示与「重试」按钮，而非空白页面

### Requirement: 进入集详情

系统 SHALL 允许用户从列表选择任一集进入该集详情页，详情页加载该集 JSON 索引并展示条目总数与总时长。

#### Scenario: 选择某一集

- **WHEN** 用户点击第 N 集
- **THEN** 进入该集详情页，展示该集条目数与总时长，并准备播放该集第一条

#### Scenario: 集索引加载失败

- **WHEN** 某集索引请求失败
- **THEN** 显示错误提示与返回/重试入口

### Requirement: 每集封面图展示

系统 SHALL 在列表与详情页为每集展示《三国演义》小人书封面图。首期 MAY 使用统一占位图；封面 MUST 支持懒加载且加载失败时回退到占位图，不得破坏布局。

#### Scenario: 展示封面

- **WHEN** 用户浏览列表或进入某集详情
- **THEN** 对应位置显示该集封面图（首期为占位图）

#### Scenario: 封面加载失败回退

- **WHEN** 某集封面图请求失败
- **THEN** 自动显示占位图，页面布局保持完整
