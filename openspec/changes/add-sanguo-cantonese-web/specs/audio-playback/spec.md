# Spec Delta

## Purpose

提供单集内多条约 8 秒 OPUS 记录的连续播放能力，含播放/暂停/切条/进度控制，并在移动端熄屏或锁屏状态下持续播放并集成系统媒体控制。

## ADDED Requirements

### Requirement: 单集连续播放

系统 SHALL 按数据集记录顺序无缝连续播放当前集的全部条目：一条播放结束后自动播放下一条，直至该集最后一条结束。播放 MUST 使用独立 OPUS 音频文件。

#### Scenario: 自动连播

- **WHEN** 当前条音频播放结束且该集仍有后续条目
- **THEN** 自动加载并播放下一条，无需用户操作

#### Scenario: 该集播放完毕

- **WHEN** 播放到该集最后一条并结束
- **THEN** 停止播放并将状态置为「已结束」，可重新从头播放该集

### Requirement: 播放控制

系统 SHALL 提供播放/暂停、上一条、下一条控制，并显示当前条序号与该集整体进度。控件状态 MUST 与实际播放状态保持同步。

#### Scenario: 播放与暂停

- **WHEN** 用户点击暂停
- **THEN** 音频立即暂停且控件切换为「可播放」状态；再次点击从当前位置继续

#### Scenario: 切换条目

- **WHEN** 用户点击下一条或上一条
- **THEN** 跳转到相邻条目并从中播放（若在暂停态则更新当前条但不强制播放）

### Requirement: 移动端熄屏后台播放

系统 SHALL 在移动端浏览器熄屏/锁屏状态下持续播放音频，并通过 Media Session 暴露媒体元数据（标题、集数）与播放/暂停、上一条/下一条动作，使用户可在锁屏界面控制播放。

#### Scenario: 熄屏后持续播放

- **WHEN** 用户在移动浏览器播放中熄屏或锁屏
- **THEN** 音频继续播放，不因页面不可见而中断

#### Scenario: 锁屏媒体控制

- **WHEN** 音频在后台播放且用户在系统媒体控制界面操作
- **THEN** 系统显示当前集/条目标题，且播放/暂停与切条动作作用于当前播放

#### Scenario: 浏览器不支持后台播放

- **WHEN** 运行环境不支持 Media Session 或后台播放被系统限制
- **THEN** 前台播放仍正常工作，并优雅降级（不报错崩溃）

### Requirement: 音频加载错误处理

系统 SHALL 在某条音频加载或播放失败时给出可见提示，并允许跳过该条继续播放后续条目，而非整体中断。

#### Scenario: 单条音频失败

- **WHEN** 某条音频请求失败或无法解码
- **THEN** 提示该条不可用并自动或手动跳到下一条继续播放
