# Spec Delta

## Purpose

在播放某集时，按数据集记录顺序滚动显示该集的繁体脚本，并随播放高亮当前句、支持点击句子定位播放，实现「听读同步」的粤语学习体验。

## ADDED Requirements

### Requirement: 按记录顺序显示繁体脚本

系统 SHALL 在集详情页按该集 JSON 索引的记录顺序（序号自 `sg_集_000` 起递增）显示每条记录的繁体 `transcription` 文本。脚本 MUST 保持繁体原样，不做简繁转换。

#### Scenario: 加载并展示脚本

- **WHEN** 用户进入某集详情页
- **THEN** 按顺序展示该集全部条目的繁体脚本文本

### Requirement: 当前句高亮与自动滚屏

系统 SHALL 在播放过程中高亮当前正在播放的条目，并自动滚动使其保持在可视区域内。当播放切换到下一条时，高亮与滚动 MUST 同步更新。

#### Scenario: 播放时高亮当前句

- **WHEN** 某条音频正在播放
- **THEN** 对应脚本行高亮显示，且自动滚动到可视区域

#### Scenario: 切换条目时同步

- **WHEN** 播放从一条切换到下一条
- **THEN** 高亮移动到新的脚本行并随之滚动

### Requirement: 点击脚本定位播放

系统 SHALL 允许用户点击任一脚本行，从该对应条目开始播放。点击 MUST 使该条成为当前播放条并更新高亮。

#### Scenario: 点击句子跳转

- **WHEN** 用户点击某条脚本行
- **THEN** 播放跳转到该条对应音频并从其开始播放，高亮更新为该行

### Requirement: 用户手动滚动时的行为

系统 SHALL 在用户手动滚动脚本时不强行拉回视图，直到播放切换到新的条目或用户重新触发定位后再恢复自动滚屏。

#### Scenario: 手动滚动不打断

- **WHEN** 用户在同一条播放期间手动滚动脚本查看其他句子
- **THEN** 视图保持在用户滚动位置，当前句高亮不变
