# Spec Delta

## Purpose

明确并展示学习语料的来源与授权，确保站点合规：数据集来源署名、CC0 1.0 Universal 公共许可证标识，以及依赖安全与插图版权的合规基线。

## ADDED Requirements

### Requirement: 数据集来源与许可证标识

系统 SHALL 在站点可见位置（页脚或「关于」页）展示数据来源（Hugging Face 的 CanCLID `zoengjyutgaai` 粤语《三国演义》评书数据集）与其 CC0 1.0 Universal 公共许可证标识，并提供指向许可证全文的链接。

#### Scenario: 查看许可证信息

- **WHEN** 用户访问页脚或「关于」页
- **THEN** 显示数据集来源署名与「CC0 1.0 Universal」标识，并可跳转到许可证全文

### Requirement: 依赖安全基线

系统 SHALL 锁定前端与构建期依赖版本，并在构建流程中执行依赖安全审计；存在已知高危漏洞的依赖 MUST 阻止发布或给出明确的处置记录。

#### Scenario: 构建期安全审计

- **WHEN** 执行构建/发布流程
- **THEN** 运行依赖安全审计，无已知高危漏洞方可发布

#### Scenario: 发现高危漏洞

- **WHEN** 审计发现高危漏洞依赖
- **THEN** 发布被阻止或要求记录处置方案，不得静默忽略

### Requirement: 插图版权合规

系统 SHALL 仅在拥有明确授权或属公有领域的前提下展示《三国演义》小人书插图；在来源与授权确定前 MUST 使用占位图，不得展示未授权图片。

#### Scenario: 授权未确定时使用占位图

- **WHEN** 某集插图的来源或授权尚未确认
- **THEN** 该集展示占位图，不加载任何未授权图片

#### Scenario: 上线前版权核查

- **WHEN** 准备以真实插图正式上线
- **THEN** 需先确认插图授权或公有领域状态，否则维持占位图
