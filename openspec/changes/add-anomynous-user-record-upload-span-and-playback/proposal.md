# Proposal

## Why

站点目前只提供评书原声的单向收听与繁体脚本对照；学习粤语最有效的路径是「跟读 — 回听对比 — 纠正」，而站点缺少让访客试讲并回听自己发音的能力，学习闭环不完整。本变更以微信语音对话的熟悉交互补上这一环：长按试讲、松开即停、气泡回听，并在离开时彻底销毁录音，规避隐私风险。

## What Changes

- 新增**微信式长按录音**：单集播放条内与「播放/暂停」同等大小、左右平行并列的圆形录音按钮（播放条不再提供前进/后退按钮；录音按钮为同色系轮廓、白色底纹，下方浅灰小字注释「錄音和AI評分」）；长按开始录制当前 span（脚本单段）并自动暂停数据集播放、显示显著文字框「你就係楷叔，快滴講尼段古仔吧」；松开停止录音。无需登录、不收集个人信息。
- 新增**本地缓存 + 后台上传**：松开后录音缓存于本地浏览器（会话期内），后台上传云端私有存储，不阻塞界面；失败自动重试；以设备本地匿名 ID 标识上传者。
- 新增**微信语音式本地回放**：录音以语音气泡（播放图标 + 时长）呈现，点击回放本地缓存；同段重录覆盖旧录音；与数据集播放互斥。
- 新增**退出即销毁**：点击「播放」、点击「选集」返回主页、任何路由切换或关闭/刷新页面时，文字框退出、本地与云端录音删除、气泡移除；云端删除带重试与卸载安全请求，服务端保留期兜底自清。
- 新增**最小服务端接口**：一个 serverless 函数仅提供签名上传与删除两操作（无列表/下载），复用现有 OSS 私有前缀；对象按匿名 ID 前缀隔离，**支持多个匿名会话并发上传各自自定义 span 的录音而互不干扰、互不可寻址**；静态站点与数据集分发方式不变。
- 不改动现有数据集连续播放、脚本同步高亮、标题/篇分组、logo 等既有行为；「发音评分」能力不在本变更实现（按钮注释文案先行）。

## 下一迭代（不在本变更范围）

- **云端录音的简易粤语发音评分**：在本变更建立的匿名上传/私有存储基础上，对已上传的 span 录音做简易粤语发音评分（如与数据集原声的时长/节奏或音素相似度对比），并在气泡上回显分数。本变更仅预留私有前缀与对象命名（`<episode>_<entryId>_<recId>.<ext>`）以便后续按 span 取回原声比对，评分算法、模型依赖与 UI 留待独立变更设计。

## Capabilities

### New Capabilities

- `user-recording`: 微信式长按试讲、本地缓存与后台上传、语音气泡本地回放、退出即销毁、并发匿名会话隔离与私有最小接口的行为契约。

### Modified Capabilities

（无：数据集播放属 `audio-playback`、脚本同步属 `script-sync`，本变更不修改其需求，仅在新交互中与之协调（暂停/互斥）。）

## Impact

- 前端：`web/src/ui/EpisodePage.tsx` 集成左下角长按录音按钮、提示文字框与语音气泡；`web/src/ui/ScriptPanel.tsx` 暴露当前 span 与暂停接口供协调；新增 `web/src/data/recorder.ts`（采集）、`web/src/data/recordings.ts`（匿名 ID、上传/删除客户端）与录音状态 hook；`web/src/config.ts` 增加录音服务地址配置（未设置时整套录音 UI 不渲染）。
- 服务端：新增 serverless 函数（签名上传、删除）与 OSS 私有前缀 `recordings/` + 保留期 lifecycle 规则；需配置函数环境变量与存储 CORS。
- 依赖：浏览器 MediaRecorder（opus/webm 回退）与 Pointer Events 长按交互；无新增前端运行时依赖。
- 部署：`tools/deploy/` 增加函数部署步骤与配置说明；静态站点部署布局（`deploy-layout`）不变。
- 隐私与合规：录音为上传者本人声音、仅本地回放、离开即销毁；服务端无列表/下载接口，保留期兜底自清。
