# Spec Delta

## Purpose

定义访客以微信语音对话的交互方式匿名试讲的能力：单集页左下角圆形按钮长按录音、松开即停、录音本地缓存并后台上传云端、以微信语音气泡形式本地回放；并在访客离开录音上下文（点击播放、返回主页、路由切换或关闭页面）时彻底销毁本地与云端录音，使「跟读 — 回听」闭环在不引入账号体系与隐私风险的前提下成立。

## ADDED Requirements

### Requirement: 微信式长按录音

系统 SHALL 在单集播放条内提供一个圆形录音按钮，与「播放/暂停」按钮同等大小、左右平行并列（播放条不再提供前进/后退按钮）。录音按钮 SHALL 采用与播放按钮同色系的轮廓描边与白色底纹，其下方 SHALL 以浅灰小字注释「錄音和AI評分」。访客长按该按钮 SHALL 开始录制当前 span（脚本单段 entry）的朗读，同时自动暂停数据集播放并以显著文字框显示「你就係楷叔，快滴講尼段古仔吧」；松开按钮 SHALL 停止录音。录音 MUST NOT 要求登录或提供任何个人信息。

#### Scenario: 进入单集页显示录音按钮与注释

- **WHEN** 访客进入任一单集播放页
- **THEN** 播放条显示「播放/暂停」与「录音」两个同等大小的圆形按钮左右平行并列，无前进/后退按钮；录音按钮为同色系轮廓、白色底纹，其下方有浅灰小字注释「錄音和AI評分」

#### Scenario: 长按开始录音并暂停与提示

- **WHEN** 访客长按圆形录音按钮且麦克风可用
- **THEN** 系统开始录制当前 span 的朗读，数据集播放自动暂停，并以显著文字框显示「你就係楷叔，快滴講尼段古仔吧」

#### Scenario: 松开停止录音

- **WHEN** 访客在录音进行中松开按钮
- **THEN** 录音停止、文字框退出，该段录音进入本地缓存

#### Scenario: 麦克风不可用时回退

- **WHEN** 浏览器不支持录音或访客拒绝麦克风授权
- **THEN** 系统显示可理解的失败原因，脚本浏览与数据集播放等既有功能不受影响

### Requirement: 本地缓存与后台上传

系统 SHALL 将松开后的录音缓存于本地浏览器（会话期内），并在后台上传至云端私有存储，上传 MUST NOT 阻塞界面操作。上传失败时系统 SHALL 自动重试，重试期间本地回放不受影响。上传者 SHALL 以设备本地匿名 ID 标识（首次使用生成，MUST NOT 关联账号或个人信息）。

#### Scenario: 松开后后台上传

- **WHEN** 访客松开按钮停止录音
- **THEN** 录音在后台上传云端，界面可继续操作，不以模态方式阻塞

#### Scenario: 上传失败自动重试

- **WHEN** 上传过程中网络或服务异常
- **THEN** 系统自动重试上传，期间本地回放可用，不产生半截可见的云端记录

#### Scenario: 首次使用生成匿名 ID

- **WHEN** 访客首次使用录音功能
- **THEN** 系统在该设备本地生成并保存匿名 ID，上传与删除均以该 ID 标识本人录音

### Requirement: 微信语音式本地回放

系统 SHALL 以微信语音气泡形式呈现当前会话内的录音：气泡带播放图标与时长，点击播放图标 SHALL 回放本地缓存的录音。对同一 span 重新录音 SHALL 覆盖该段旧气泡与旧云端对象。录音回放与数据集播放 MUST 互斥，避免两路声音叠加。

#### Scenario: 气泡回放本地录音

- **WHEN** 访客点击某条录音气泡的播放图标
- **THEN** 系统回放该段本地缓存录音，气泡显示播放状态与时长

#### Scenario: 同段重录覆盖

- **WHEN** 访客对已有录音的 span 再次长按录音并松开
- **THEN** 该段仅保留最新一条录音：旧气泡被替换、旧云端对象被删除

#### Scenario: 与数据集播放互斥

- **WHEN** 回放录音时数据集原声正在播放（或反之）
- **THEN** 系统暂停另一方音频，避免两路声音叠加

### Requirement: 退出即销毁

系统 SHALL 在访客离开录音上下文时销毁录音：点击「播放」按钮、点击「选集」返回主页、任何其他路由切换、关闭或刷新页面均 SHALL 触发销毁。销毁 SHALL 同时移除文字框、本地缓存、云端录音与回放气泡；云端删除 MUST 确保完成（客户端重试、页面卸载时发出卸载安全请求、服务端保留期到期兜底自清）。

#### Scenario: 点击播放销毁

- **WHEN** 存在录音时访客点击「播放」按钮
- **THEN** 文字框退出、回放气泡移除、本地缓存与云端录音被删除，随后数据集正常播放

#### Scenario: 返回主页销毁

- **WHEN** 存在录音时访客点击「选集」返回主页
- **THEN** 主页不残留任何录音痕迹，本地缓存与云端录音被删除

#### Scenario: 关闭或刷新页面销毁

- **WHEN** 存在录音时访客关闭或刷新页面
- **THEN** 客户端在卸载前发出删除请求；即使该请求未送达，云端录音亦在保留期到期后被自动清除

#### Scenario: 销毁后不可回放

- **WHEN** 销毁完成后访客回到该集
- **THEN** 不显示任何录音气泡，亦无法回放已销毁的录音

### Requirement: 私有存储与最小接口

服务端 SHALL 仅提供签名上传与删除两类操作，MUST NOT 提供录音列表或下载接口；录音对象 MUST 存于私有存储且仅经短时签名 URL 写入，任何访客 MUST NOT 通过猜测或构造 URL 读取他人录音。

#### Scenario: 无列表与下载接口

- **WHEN** 任何客户端请求录音列表或下载操作
- **THEN** 服务端不提供该操作（请求被拒绝），界面亦不存在依赖该操作的入口

#### Scenario: 他人不可读取

- **WHEN** 某访客尝试以构造的 URL 或签名访问他人录音对象
- **THEN** 请求被拒绝，无法取得录音内容

### Requirement: 并发匿名会话隔离

系统 SHALL 支持多个匿名会话同时上传各自自定义 span 的录音，且这些录音 MUST 相互隔离：每个会话的对象仅存于其匿名 ID 前缀下，任一会话的上传、覆盖（同段重录）与删除操作 MUST NOT 影响、寻址或泄露其他并发会话的对象。删除操作的归属校验 SHALL 仅依据请求所携带的匿名 ID 重建对象 key，客户端 MUST NOT 通过传入完整 key 或他人匿名 ID 来越权操作。

#### Scenario: 并发上传互不干扰

- **WHEN** 多个不同匿名 ID 的会话在同一时间各自上传录音
- **THEN** 每条录音仅落于其本人匿名 ID 前缀下，任一会话的成功或失败不影响其他会话的上传结果

#### Scenario: 并发下的删除仅限本人

- **WHEN** 某会话发起删除，且云端同时存在其他匿名会话的录音
- **THEN** 仅该会话本人前缀下匹配的对象被删除，其他会话的对象保持不变、不可被该请求寻址

#### Scenario: 同段重录覆盖仅作用于本人

- **WHEN** 某会话对同一 span 重录并覆盖旧录音，与此同时其他会话也在录制同一 span
- **THEN** 覆盖仅替换该会话本人的旧对象，其他会话对同一 span 的录音不受影响
